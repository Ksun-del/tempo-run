# Темп — приложение для бега (Android)

Запись пробежки по GPS с картой, голосовые подсказки, история тренировок и карточки для сторис с фото, треком и статистикой.

## Что умеет

- **Запись пробежки**: старт / пауза / финиш, живая карта с треком, дистанция, время, темп сейчас и средний, точность GPS. Запись продолжается с заблокированным экраном (через уведомление «Идёт тренировка»).
- **Голосовые подсказки** на русском: каждый 1 / 2 / 5 км — дистанция, общее время и время последнего километра; итог в конце.
- **История**: итоги за неделю / месяц / год с графиком, список пробежек, детали со сплитами по километрам и картой маршрута, можно переименовать или удалить.
- **Карточка**: фото с камеры или из галереи (или без фото), 5 шаблонов (Классика, Трек, Минимал, Постер, Сплиты), формат 9:16 для сторис или 4:5 для поста, 5 цветов акцента. Сохранение в галерею (1080 px) или «Поделиться» сразу в Instagram/Telegram.
- **Демо-пробежка** в Настройках, чтобы посмотреть историю и карточки без реального бега.

Все данные хранятся только на телефоне. Карта — OpenStreetMap / CARTO, ключи API не нужны.

## Вариант 1. Установить APK на телефон (рекомендуется)

Понадобится компьютер с [Node.js LTS](https://nodejs.org) и бесплатный аккаунт на [expo.dev](https://expo.dev/signup). Сама сборка идёт в облаке Expo, Android Studio не нужна.

```bash
cd tempo-run
npm install
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview
```

На вопросы в процессе отвечай «Yes» (создать проект, сгенерировать ключ подписи). Через 10–20 минут появится ссылка и QR-код — открой её на телефоне, скачай APK и установи (Android попросит разрешить установку из этого источника).

## Вариант 2. Быстро посмотреть через Expo Go

```bash
cd tempo-run
npm install
npx expo start
```

Установи **Expo Go** из Google Play и отсканируй QR-код из терминала (телефон и компьютер в одной Wi-Fi сети).

Ограничения Expo Go: запись идёт только при включённом экране (приложение само не даст ему погаснуть и покажет предупреждение), сохранение в галерею может не работать — используй «Поделиться». В APK из варианта 1 этих ограничений нет.

## Советы для точного трека

- Перед стартом подожди пару секунд на главном экране, пока найдётся GPS.
- Если трек обрывается с заблокированным экраном: Настройки телефона → Приложения → Темп → Батарея → «Без ограничений» (особенно на Xiaomi, Huawei, Honor, Samsung).
- Разреши уведомления — так видно, что запись идёт.

## Структура

```
src/app/            экраны (Expo Router)
  (tabs)/index.tsx    главный: карта и кнопка СТАРТ
  (tabs)/history.tsx  история и статистика
  (tabs)/settings.tsx настройки
  run.tsx             экран тренировки
  activity/[id].tsx   детали пробежки
  share/[id].tsx      редактор карточки
src/lib/tracker.ts  запись GPS (foreground service, фильтрация точек, сплиты)
src/lib/voice.ts    голосовые подсказки
src/lib/storage.ts  хранение пробежек
src/components/templates/  шаблоны карточек
src/components/RunMap.tsx  карта (Leaflet внутри WebView)
```

Стек: Expo SDK 57, React Native 0.86, TypeScript.
